# 🎮 GTA VI — Landing Page Promocional

> Projeto de portfólio: landing page temática inspirada na estética de Vice City.

---

## 📝 Sobre o projeto

Esta é uma landing page estática criada para apresentar conteúdos promocionais de maneira imersiva, com foco em vídeo, estética neon e interatividade. O objetivo principal é demonstrar habilidades em HTML, CSS e JavaScript puro, além de técnicas de responsividade e controles customizados de mídia.

---

## 🚀 Funcionalidades

- Vídeo de fundo imersivo na seção hero (arquivo: `video-capa.mp4`).
- Card de trailer interativo para reprodução do trailer oficial.
- Estética inspirada em Vice City com cores neon e animações suaves.
- Player de vídeo com controles personalizados (play/pause, volume, progresso).
- Layout moderno e intuitivo, otimizado para navegação clara.
- Design responsivo para desktop, tablet e dispositivos móveis.

---

## 🧰 Tecnologias utilizadas

- HTML5 — estrutura semântica e acessível.
- CSS3 — estilização, responsividade e animações.
- JavaScript — controle de mídia, manipulação do DOM e interatividade.
- Git & GitHub — versionamento e hospedagem (GitHub Pages).

---

## 📁 Estrutura do repositório

- index.html — página principal / landing page.
- /assets
  - /css — arquivos de estilo.
  - /js — scripts JavaScript.
  - /media — vídeos e imagens (ex.: `video-capa.mp4`).

> Obs: adapte os caminhos se necessário ao organizar os arquivos locais.

---

## 🔧 Como executar localmente

1. Clone o repositório:

   git clone https://github.com/JoaoPedroS-S/GTA-VI.git

2. Entre na pasta do projeto:

   cd GTA-VI

3. Abra o arquivo `index.html` no seu navegador ou sirva com um servidor local (recomendado para reprodução de vídeo e CORS):

   - Usando Python (porta 8000):
     - Python 3: `python -m http.server 8000`
     - Acesse: http://localhost:8000

   - Ou use uma extensão/servidor estático de sua preferência (Live Server, http-server, etc.).

---

## 📱 Responsividade e acessibilidade

- Design responsivo com media queries para vários tamanhos de tela.
- Uso de elementos semânticos (header, main, footer) para melhorar navegação e SEO.
- Recomenda-se adicionar atributos `alt` às imagens e controles acessíveis (aria-labels) nos botões do player de vídeo.
