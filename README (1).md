# 🎮 GTA VI — Landing Page Promocional

> **Web Development Showcase** | Projeto de landing page temática e imersiva inspirada na estética de Vice City.

---

## 📝 Descrição do Projeto

O projeto **GTA VI** é uma landing page temática e imersiva desenvolvida para apresentar conteúdos exclusivos, vídeos promocionais e detalhes do aguardado jogo *Grand Theft Auto VI*. 

A aplicação conta com um design moderno inspirado em Vice City, com elementos visuais dinâmicos, reprodução de vídeo e animações para proporcionar uma excelente experiência ao usuário.

---

## 🚀 Funcionalidades em Destaque

| Ícone | Funcionalidade | Descrição |
| :---: | :--- | :--- |
| ✨ | **Vídeo de Fundo Imersivo** | Exibição de vídeo (`video-capa.mp4`) na Hero Section para alto impacto visual. |
| 🎬 | **Trailer Interativo** | Card temático estilizado para reprodução do trailer oficial do jogo. |
| 🌈 | **Estética Vice City Neon** | Design com tons vibrantes, transições suaves e efeitos retro-futuristas. |
| 🔊 | **Player de Vídeo Dinâmico** | Controles de mídia personalizados com botões estilizados de interação. |
| 🖥️ | **Layout Moderno** | Navegação simples, limpa e intuitiva focada na experiência do usuário. |
| 📱 | **Design Responsivo** | Adaptação fluida para computadores, tablets e dispositivos móveis. |

## 🎯 Objetivos de Aprendizado

- 🎨 **Identidade Visual:** Criar um projeto altamente atraente baseado no universo visual do GTA VI.
- 🚀 **Frontend Nativo:** Praticar a construção de interfaces modernas com HTML, CSS e JS puro.
- 🎥 **Mídia e Interatividade:** Manipular a exibição e controle de vídeos e áudios via web.
- 📱 **Multi-dispositivos:** Aplicar técnicas avançadas de responsividade para diferentes resoluções.
